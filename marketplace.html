DS4CC

The family is four plugins in a 20-plugin marketplace.

ds4cc.com / VeigaPunk/ds4cc-marketplace is the public catalog for Grok Build, Codex, Kimi Code CLI, and OpenCode. The Musketeer adapters ship there as the-musketeer the-puppeteer the-almanacker the-kimiraikoner.

register + family
grok plugin marketplace add VeigaPunk/ds4cc-marketplace
for p in the-musketeer the-puppeteer the-almanacker the-kimiraikoner; do
  grok plugin install "$p" --trust && grok plugin enable "$p"
done

What a plugin is

Skills and agent specs the host CLI can load. Validated by a Rust binary. Actionable SKILL.md only — docs-only payloads are rejected. This is not a substitute for musketeer-chrome or the host CLIs in the four public repos.

Spelling that matters

Product and GitHub repo: the-kimiraikkoner (double k). Marketplace disk slug: the-kimiraikoner. grok plugin install uses the disk slug. The CLI binary is never named kimi.
